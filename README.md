# Student Data Organizer

A Python-based student management project that allows users to store and manage student information through a simple menu-driven program.

## About

The program stores student details such as student ID, name, age, grade, date of birth, and subjects. Users can add new students, view existing student records, update information, delete students, and view the subjects offered.

## Features

* Add student details
* Display all student records
* Update student age
* Update student subjects
* Delete student records
* Display unique subjects offered
* Simple menu-driven interface

## Information Stored

Each student record contains:

* Student ID
* Name
* Age
* Grade
* Date of Birth
* Subjects

## Technologies Used

* Python

## Python Concepts

* Lists
* Dictionaries
* Tuples
* Sets
* Loops
* Conditional statements
* User input

## How to Run

```bash
python collection_manipulator_.py
```

Follow the options shown in the terminal to manage the student records.
